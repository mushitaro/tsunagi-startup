趣味で米国株を運用しています。ルールは決めているのに、毎回手動で注文を入れるのが手間でした。自分の売買ロジックをそのまま自動化できないか、という動機から作り始めたのが TSUNAGI Stocks です。

## moomoo を選んだ理由

自動売買には、外部からプログラムで注文を送れる API が必要です。日本の証券会社も含めて調べましたが、個人が使えるレベルで売買 API を提供しているのは moomoo（富途証券）だけでした。そこで moomoo に口座を開いてアプローチを確認し、開発を進めることにしました。

## 動いたこと

moomoo が提供するローカルゲートウェイ（OpenD）経由で API を叩き、ウォッチリストの価格取得と売買注文の送信を実装しました。テスト環境での動作は確認済みで、整数株（1株単位）の売買であれば意図した通りに動きます。

## 動かなかったこと — 端数株の壁

米国株では端数株（fractional shares、1株未満の取引）に対応している証券会社が多く、自分もそれを前提に運用していました。ところが moomoo の API は端数株注文に対応していないことが判明しました。整数株のみに切り替えれば使える状態ですが、現在の運用スタイルとは合わないため、実際の売買には使っていません。

## オープンソースとして公開する

動く状態のコードを手元に眠らせておくより、同じことを試したい人の参考になった方がよいと思い、GitHub で公開しています。整数株で運用している方や、moomoo API を使った自動売買の仕組みを調べている方に役立てれば。

API キーは環境変数で管理するよう修正したうえで公開しています。セットアップ手順はリポジトリの README に記載しています。
